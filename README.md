# Per Item Shipping for WooCommerce

A WooCommerce shipping method with a base charge for the first item and an additional charge for each subsequent item.

## Installation and use

1. Place the `per-item-shipping` folder in `wp-content/plugins/`.
2. Activate Per Item Shipping for WooCommerce in the WordPress Plugins screen.

Activate WooCommerce, add the per-item shipping method to a shipping zone, and set the base and additional-item costs.
